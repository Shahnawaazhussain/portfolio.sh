# Shahnawaaz Hussain — Bold & Creative Portfolio v2

Responsive static portfolio built with HTML, CSS and vanilla JavaScript.

## Design direction
- Editorial / expressive visual style with oversized typography.
- DM Sans for display and body text, Playfair Display italic for contrast, DM Mono for labels.
- Warm paper, ink-black, vivid orange and acid-lime palette.
- Responsive layouts and mobile navigation.

## Run
Open `index.html` in a browser. No build tools required.

## Before publishing
1. Replace CSS-made project previews with real screenshots from your work.
2. Add your Behance, live demo, GitHub and LinkedIn URLs in `script.js`.
3. Verify project descriptions, dates and role statements.
4. Test on desktop, tablet and mobile.

Note: Project previews are illustrative CSS mockups, not actual product screenshots.
